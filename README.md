# Toward-a-more-precise-immunophenotypic-definition-of-human-cMoPs
We used scRNA-seq to compare CLEC12A+CD64hi and CD115+CD64hi/int monocyte progenitors (cMoPs) and assess whether they represent the same population. Our analysis revealed that CD115-based gating more accurately captures the cMoP transcriptional identity, refining their definition at single-cell resolution.
